# Business Case — [Product/Service Name: Canvas Bookmarks]

## 1. Problem / Opportunity
What's the situation today, and why does it matter? (1–2 sentences)

- Students use Canvas as the facilitator for their online coursework, 
with all courses being separate entities controlled by their own professor with different course structure and layout.
- Students cannot easily access multiple course files without switching between course tabs.

## 2. Proposed Solution
One paragraph, plain language, no implementation detail.

Our proposed solution is to explore options that aid students in coursework discovery, file access, and time management by allowing personalized saving, assignment retention, and review of coursework in a manner that encourages engagement.

## 3. Options Considered

| Option | Description | Pros | Cons |
|--------|-------------|------|------|

| Option A: Personalized Canvas Application | Description: A Canvas course page that the user manipulates to save files, coursework, etc from currently enrolled Canvas courses | Pros: User controlled, personalized,  | Cons: User training, development cost, getting users to implement separate application|

| Option B: Personalized Course Folder (recommended) | Description: Each instructor-controlled Canvas course will include a personalized student folder for specific user to save coursework,  | Pros: Built in to course, consistent across enrollment, personalized folder for each course aids in organization and time management | Cons: Backend customization for each student, user training, instructor training & implementation standards |

## 6. Priority & Urgency
Why now? What happens if we wait or don't do it?

Why now: Begin case with goal to roll-out Canvas changes in Fall 2027. This gives us adequate time for user research, testing, and debugging before the 2027-2028 school year. If we wait, we will likely have to wait for roll-out the following year. If we do not implement, students could miss out on enriching personalization on their coursework.
